# グリードアイランド風カード探索RPG プロジェクトブリーフ

最終更新: 2026-06-21

## 目的

カードシステムと探索を組み合わせた新規ゲームプロダクトを、Unreal Engine 5.8 を前提に検証する。既存IPの再現ではなく、「カードがゲームのルールを書き換える」構造を中心に、オリジナル世界観・オリジナルカードで成立する新規体験を作る。

## ワンライナー

ダンジョンマスターが本物のAIで、それを出し抜くカードRPG。

## 重要な前提

- ハンター×ハンターのキャラクター、固有名詞、世界観、カード名、設定は使用しない。
- 参考にするのは「カードが探索・戦闘・交渉・収集ルールを変える」というメカニクスのみ。
- SHOGUNとは別ラインの新規プロダクト案として扱う。
- MVPではオンライン経済、PvP、大規模トレード市場は作らない。
- 最初の検証では、AIはゲーム状態を直接改変しない。AIは提案・会話・クエスト文面を生成し、最終的な状態変更はC++のルールエンジンが検証する。

## UE5.8前提の確認メモ

2026-06-21時点で、Epic Games公式情報では Unreal Engine 5.8 は公開済み。公式ニュースでは UE5.8 が「最後に予定されているUE5メジャーリリース」とされ、Mesh Terrain、Experimental MCP plugin、MetaHuman Collections、MegaLights Production-Ready などが紹介されている。

## プロダクトの核

この企画の中心は、カードバトル単体でも、3D探索単体でもない。カードがルール層に干渉し、プレイヤーがカード同士の制約・例外・優先順位を読み解くことで「想定外の突破」を作る体験である。

例:

- 「通常は1ターンに1回しか移動できない」を、移動ルール変更カードで上書きする。
- 「4人パーティでのみ使用可」という制約カードを、NPC契約カードで一時的に満たす。
- 「戦闘中のみ有効」なカードを、探索イベントを戦闘扱いに変えるカードで起動する。
- AI GMが提示した交渉条件に対し、カードのルール解釈で別解を通す。

## 初期MVPのゴール

2週間の初期MVPでは、完成ゲームではなく「この体験が成立するか」を確認する。

成功条件:

- 1ゾーンの3D探索ができる。
- 探索中にカードを獲得できる。
- 15から20枚程度のカードがデータ駆動で読み込まれる。
- 少なくとも5枚は、単純な攻撃・回復ではなくルールや制約に干渉する。
- 簡易カードバトルUIで、カード効果と制約判定が確認できる。
- AI GM v0として、NPC会話またはクエスト文面生成が1箇所で動く。
- AI出力はC++側の許可リストとスキーマ検証を通った場合のみゲーム状態に反映される。

## 作らないもの

初期MVPでは以下を作らない。

- MMO的な同期プレイ
- プレイヤー間マーケット
- 本格PvP
- 大規模なカード総数
- 複数ゾーンの広いワールド
- MetaHuman群衆の本格運用
- 本番課金
- モバイル最適化
- IP由来の名称・演出・固有デザイン

## 最初に確定すべき意思決定

- カード定義を JSON / DataTable / DataAsset のどれを正とするか
- AI GMをランタイム機能として入れる前に、開発支援のMCP検証をどこまで行うか
- MVPの保存先をローカル優先にするか、Supabase最小実装まで含めるか
- 戦闘をターン制カードバトルにするか、探索イベント解決に近い軽量バトルにするか
- ルールハックの最小デモをどの3コンボで見せるか
